# XO-Multiplayer-Tic-tac-toe-game-in-Java-using-TCP-sockets
Jeu de morpion multijoueur en Java, développé avec une architecture client-serveur utilisant les sockets TCP et une interface graphique Swing. Le projet gère les parties à deux joueurs, les tours, le chat et la revanche. Réalisé dans le cadre du module Programmation Réseau en 4ᵉ année à l’ENSTTIC.
